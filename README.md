# MPG Dataset Visualization using ggplot2 & Patchwork

## 📌 Project Overview

This project demonstrates how to create multiple data visualizations in **R** using the **ggplot2** package and combine them into a single dashboard with the **Patchwork** package.

The dashboard provides insights into vehicle characteristics and fuel efficiency using the built-in **mpg** and **mtcars** datasets.

---

## 📊 Visualizations Included

- 📍 Scatter Plot
- 📍 Bar Chart
- 📍 Box Plot
- 📍 Histogram

All four visualizations are combined into a single dashboard using the **Patchwork** package.

---

## 🛠️ Technologies Used

- R Programming
- ggplot2
- Patchwork

---

## 📂 Dataset

This project uses two built-in datasets available in **R**:

- **mtcars** – Motor Trend Car Road Tests dataset
- **mpg** – Fuel economy dataset

> No external datasets are required.

## 🚀 How to Run

### Install Required Packages

```r
install.packages("ggplot2")
install.packages("patchwork")
```

### Load the Libraries

```r
library(ggplot2)
library(patchwork)
```

### Run the Project

Open the R script in **RStudio** and execute the code to generate the dashboard.
